# PhoneGate wiki

PhoneGate keeps your Windows PC locked until you approve each unlock on your Android phone. It
stays secure even if an attacker has the full source code and controls the server.

## Start here

1. [Hosting the relay](Hosting-the-relay.md): the small server your PC and phone meet on
2. [Installing on Windows](Installing-on-Windows.md): the setup wizard
3. [Installing the phone app](Installing-the-phone-app.md): moving the APK to your phone
4. [Pairing and first unlock](Pairing-and-first-unlock.md)
5. [Recovery and offline access](Recovery-and-offline-access.md): never get locked out
