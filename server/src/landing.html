PhoneGate Relay

Nothing to see here.

This server is a PhoneGate relay. It passes encrypted messages between paired PCs and phones, and there is nothing to sign in to.

View on GitHub
What it sees
Sealed envelopes, device ids and timing. Never what a request says.
What it can't do
Read a request, approve a sign-in, or replay an old approval.
If it goes down
Owners still sign in with an offline code or a recovery code.

Open source under Apache-2.0. Run your own relay.
